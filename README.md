# Hearth

A Windows app for hanging out with friends: calls, movies, games, drawing, and shared tools.

**[Download the latest Windows installer](https://github.com/colemanimation/Hearth-Releases/releases/latest)**

Run the setup .exe. That single file is all your friend needs. Install over an existing copy to retain personal settings and your library. Hearth 0.1 users must install 0.2 once manually; later versions can download inside Hearth.

Hearth checks for updates after startup and every four hours when enabled. It downloads updates and waits for you to leave your room and choose **Restart and install**. You can also check from Settings > About.

Create a room and send its invitation through your usual messenger. Everyone needs Hearth 0.2 or later and a fresh invitation. The host must keep Hearth open. Saved rooms reuse an invitation when the host returns.

## In Hearth 0.2

- Four chess tables and Games & Apps windows in the main stage.
- YouTube and a shared browser with control handoff.
- Image/GIF sets, transparency tools, and snapshots of cameras or shared content.
- Soundboard recordings up to 20 seconds.
- Face/content filters, animated silhouette theater, and fullscreen tool drawers.
- Window sharing that omits the cursor to prevent a cursor appearing over the wrong window.

Early access for Windows x64, Windows 10 build 19041 or later. The installer is currently unsigned. Some protected media or websites may not work in the shared browser. See each release's notes and verification file for tested scope.

This repository distributes official installers, update metadata, checksums, and user documentation. Hearth's development repository remains private.
